# AESTHETIX Athletic Club

A premium, dark-themed landing page for an elite fitness club. Built with plain HTML, CSS, and vanilla JavaScript — no build tools, no frameworks, just the web platform.

![Status](https://img.shields.io/badge/status-live-brightgreen) ![Made with](https://img.shields.io/badge/made%20with-HTML%20%7C%20CSS%20%7C%20JS-red)

## About

AESTHETIX is a fictional high-performance athletic club. This project is the homepage — a single-page marketing site featuring a cinematic hero, class previews, facility tours, nutrition consultations, trainer profiles, an interactive timetable, testimonials, and a pricing section with a working billing toggle.

The design leans into a high-contrast dark aesthetic: pitch blacks, sharp crimson accents, and disciplined geometric typography.

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Sticky navigation with expandable search
- Class category filtering
- Facility video tour modals
- Nutrition specialist carousel
- Interactive timetable calendar
- Testimonial rotation
- Monthly / yearly pricing toggle
- Membership signup modal
- Toast notifications for user actions
- Scroll-triggered hero animations

## Tech Stack

- **HTML5** — semantic markup
- **Tailwind CSS** (via CDN) — utility-first styling with a custom theme
- **Vanilla JavaScript** — all interactivity, no libraries
- **Google Fonts** — Space Grotesk & Inter
- **Material Symbols** — icon set
